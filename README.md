## 🧩 How I think

I don't particularly enjoy treating libraries like magic.

If something works, I want to know:

**Why does it work?**  
**What's happening underneath?**  
**What breaks when the assumptions change?**

That's why I enjoy implementing concepts from scratch, experimenting with systems, and then comparing them with production libraries.
